About

I'm a full stack developer at MaintWiz Technologies in Chennai, working on MaxMold — a platform that gives manufacturers a live, structured view of every mould and machine they run, instead of spreadsheets and gut feel.

Most of my day lives in Angular: signal-based forms, dashboards built on GridStack and ApexCharts, and performance work on components that need to stay fast under real industrial data volumes. On the other side, I work through the Spring Boot services, Keycloak auth, and AWS infrastructure that keep the platform multi-tenant and reliable.

I like the kind of problem where the fix is a genuinely better algorithm or data structure, not just more code — and where the end user is someone running a factory floor, not just another dashboard.

MaxMold — industrial mould lifecycle & IoT platform

A multi-tenant SaaS platform that tracks mould and machine health across a manufacturer's whole operation, combining configuration, IoT telemetry, and live dashboards in one system.

Angular 22 Spring Boot AWS IoT Core RabbitMQ Keycloak
  • Rebuilt selection logic in a 645-node tree view from O(n²) to near-constant-time lookups using a computed flat-node signal and an index map, removing the dominant UI bottleneck.
  • Migrated core forms to Angular's signal-first patterns — reactive validation, computed state, and toast-driven feedback — as part of an in-progress Angular 22 migration.
  • Built the backend-driven dashboard system on GridStack and ApexCharts, with drag/resize layouts persisted per user and iframe widgets rendered safely via sanitized URLs.
  • Applied a BFF pattern over the Spring Boot services — aggregating APIs, handling Keycloak auth, and fanning out parallel calls with CompletableFuture for dashboard view-models.
